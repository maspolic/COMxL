COMXL

Classical optimization made interactive, fast, and completely transparent

Notebook COMxL Excel Add-In

An interactive optimization solver, inspired by and built to support Dr. Jude Bonsu’s Computer Optimization Methods course. COMXL brings classical optimization algorithms directly to your web browser. Originally developed as an Excel/VBA workbook that printed iteration results line-by-line, this modern Python web app runs the exact same algorithms locally. Experience clear, step-by-step solution traces and complete iteration tables—with zero setup, instant results, and total data privacy

Everything executes locally in your browser via Pyodide
