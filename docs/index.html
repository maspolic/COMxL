COMXL

Classical optimisation with the working shown

Repository Notebook

A pure-Python port of the COMxL Excel/VBA optimisation workbook. The original drove worksheet formulas from VBA user forms and wrote each iteration back onto the sheet. This page runs the same algorithms in your browser and shows the same iteration tables — no install, no server, nothing uploaded.

Everything executes locally in your browser via Pyodide, using the same comxl package the repository ships and tests.

First load pulls down Python, NumPy, pandas and Matplotlib (around 15 MB). It is cached afterwards.
